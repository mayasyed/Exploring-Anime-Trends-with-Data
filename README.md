# 📊 Anime 101: Using Data to Find My First Anime

👩‍💻 I’ve never watched anime before, but my partner loves it.  
Instead of relying on memes or chaotic clips online, I took a *data-driven* approach to decide where I should begin.

I analysed over **12,000+ anime titles** to figure out:
what’s popular, what’s highly rated, and what beginner-friendly shows are actually worth trying.

---

## ❓ Questions I Explored

- 🎭 What genres are most popular?
- ⏳ Do people prefer short or long anime?
- 🌟 What are the highest-rated short anime for first-timers?

---

## 🛠 Skills Displayed

- 🧹 **Data Cleaning**: Removed duplicates, handled missing values, and fixed messy genre data.
- 🔄 **Data Wrangling**: Split multi-label genre fields into structured lists for analysis.
- 🔍 **Exploratory Data Analysis (EDA)**: Found patterns in ratings, episode counts, and genre trends.
- 📊 **Data Visualisation**: Created clean, engaging charts using Matplotlib and Seaborn.
- 🧠 **Storytelling**: Framed the analysis around a relatable question for beginners.
- 💻 **Git & GitHub**: Managed version control and structured the project for public sharing.

---

## 🧰 Tools Used

- 🐍 Python (`pandas`, `matplotlib`, `seaborn`)
- 📓 Jupyter Notebook
- 🌐 GitHub

---

## ✅ Outcome

I created a shortlist of anime series I’d actually be willing to try — backed by data, not just hype or memes.  
The result? A fun and insightful exploration of anime from a complete beginner’s perspective 📈🎌

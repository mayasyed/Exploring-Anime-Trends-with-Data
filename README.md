# Anime 101: Using Data to Find My First Anime

I’ve never watched anime before, but my partner loves it. Instead of relying on memes or chaotic clips online, I took a data-driven approach to decide where I should begin. I analysed over 12,000 anime titles to understand what’s popular, what’s highly rated, and what’s beginner-friendly.

## Questions I Explored
- What genres are most popular?
- Do people prefer short or long anime?
- What are the highest-rated short anime for first-timers?

## Skills Displayed

- **Data Cleaning**: Removed duplicates, handled missing values, and cleaned messy genre data.
- **Data Wrangling**: Converted multi-label genre fields into structured lists for analysis.
- **Exploratory Data Analysis (EDA)**: Identified patterns in ratings, episode counts, and genre trends.
- **Data Visualisation**: Created clear, styled plots using Matplotlib and Seaborn.
- **Storytelling**: Framed the project around a relatable, real-life scenario to make insights engaging.
- **Git & GitHub**: Version control and open-source project structure for public sharing.

## Tools Used
- Python (pandas, matplotlib, seaborn)
- Jupyter Notebook
- GitHub

## Outcome
I created a shortlist of anime series I’d actually be willing to try, based entirely on the data!
